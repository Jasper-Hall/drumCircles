# samples

Eight one-shots from Sonic Pi's bundled sample library
(github.com/sonic-pi-net/sonic-pi, `etc/samples`), released CC0 (public
domain) by the Sonic Pi project. Re-encoded to `.m4a` for size; used here by
the `smpl` track's sample selector, each mapped to a `Tone.Sampler` at `C3`
so grid notes repitch the one-shot along the scale.

| file                       | selector label |
|-----------------------------|-----------------|
| `drum_heavy_kick.m4a`        | kick            |
| `drum_snare_hard.m4a`        | snare           |
| `drum_cymbal_closed.m4a`     | hat             |
| `drum_cymbal_open.m4a`       | open hat        |
| `drum_tom_mid_hard.m4a`      | tom             |
| `drum_cowbell.m4a`           | cowbell         |
| `perc_snap.m4a`              | snap            |
| `elec_hi_snare.m4a`          | e-snare         |
